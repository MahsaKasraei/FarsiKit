# Contributing to FarsiKit

Thanks for helping improve Persian-language developer tools.

## Development

1. Fork the repository.
2. Create a branch for your change.
3. Install dependencies with `npm install`.
4. Run tests with `npm test`.
5. Run the playground with `npm run dev`.
6. Open a pull request with a clear description and examples.

## Guidelines

- Keep utilities framework-agnostic where possible.
- Add tests for behavior changes.
- Prefer explicit options over surprising automatic transformations.
- Include Persian examples when fixing language-specific behavior.
- Avoid claiming linguistic completeness for heuristic rules.

## Reporting issues

Please include a minimal input example, expected output, actual output, and Node.js version when relevant.
